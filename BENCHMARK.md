# Meeting and broadcast mobile scorecard

Scored from the mobile pass in `QUIRKS.md`, not from a feature checklist. Scale is 1–5. A 5 means that audience would rather use this than the product that usually wins for them. We do not lead any audience yet.

Competitors this is held against: Zoom, Google Meet, Microsoft Teams, FaceTime, StreamYard, YouTube Live, and church streaming desks (Resi, BoxCast, ProPresenter-style “go live” panels).

## Where they still beat us

- **Zoom / Meet / Teams.** The hang-up, mute, and camera controls stay inside the screen on a 320px phone. Chat is a sheet or a column that does not sit under the call dock.
- **FaceTime.** One primary action, huge targets, no password essay, the preview is the screen.
- **StreamYard / YouTube Live.** The state is a banner now (Q14). They still win the program monitor and the screen a viewer gets when the broadcast has ended.
- **Church desks.** A volunteer names the service and goes on. This path now opens on the service name and Go live (Q25). The host key stays behind Change. A desk still has no key.

Hang up stays on screen (Q1). Chat sits above the dock, including under a keyboard (Q2). A broadcast state is a full-width banner above the status sentence (Q14). Create & enter stays in the card while the room fields scroll (Q4). More scrolls inside a short landscape screen (Q3). The chip and the dock clear a notch and a home indicator (Q7). The status line and the chip title grow with the root text size (Q6, Q13). Flip sits on the phone dock (Q5b). Create asks for one host password (Q12). The dock gap is at least 8px (Q10). Continue is the only filled join action (Q11).

Corporate, church, and personal are 4.0. None lead. A 5 would mean that audience would switch. Warm copy for church is 4: the first screen is the service name and Go live, and the host key stays behind Change (Q25). It is not a 5. A church desk still goes on with no host key. Landscape is 4: the title chip keeps its band, and the face uses the dock's band until you tap (Q26). It is not a 5. Meet still lays a thinner bar on the picture when the controls are up. Large type is 4: chat, the composer, and the lobby sentence grow with the root font (Q21, Q24). FaceTime still wins that dimension. The dock stays a fixed size.

## Next gap

None of these are a 5. Meet still wins once the controls are up on a rotated call, because its bar is thinner and sits on the picture. FaceTime still wins large type, because the dock does not grow with the text. A church desk still has no host key.
