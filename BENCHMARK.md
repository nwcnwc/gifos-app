# Meeting and broadcast mobile scorecard

Scored from the mobile pass in `QUIRKS.md`, not from a feature checklist. Scale is 1–5. A 5 means that audience would rather use this than the product that usually wins for them. We do not lead any audience yet.

Competitors this is held against: Zoom, Google Meet, Microsoft Teams, FaceTime, StreamYard, YouTube Live, and church streaming desks (Resi, BoxCast, ProPresenter-style “go live” panels).

## Where they still beat us

- **Zoom / Meet / Teams.** The hang-up, mute, and camera controls stay inside the screen on a 320px phone. Chat is a sheet or a column that does not sit under the call dock.
- **FaceTime.** One primary action, huge targets, no password essay, the preview is the screen.
- **StreamYard / YouTube Live.** The state is a banner now (Q14). They still win the program monitor and the screen a viewer gets when the broadcast has ended.
- **Church desks.** A volunteer names the service and goes on. This path now opens on the service name and Go live (Q25). The host key stays behind Change. A desk still has no key.

Hang up stays on screen (Q1). Chat sits above the dock, including under a keyboard (Q2). A broadcast state is a full-width banner above the status sentence (Q14). Create & enter stays in the card while the room fields scroll (Q4). More scrolls inside a short landscape screen (Q3). The chip and the dock clear a notch and a home indicator (Q7). The status line and the chip title grow with the root text size (Q6, Q13). Flip sits on the phone dock (Q5b). Create asks for one host password (Q12). The dock gap is at least 8px (Q10). Save is the only filled join action, and Clear blanks the name and the picture in the form (Q31).

Corporate, church, and personal are 4.0. None lead. A 5 would mean that audience would switch. Warm copy for church is 4: the first screen is the service name and Go live, and the host key stays behind Change (Q25). It is not a 5. A church desk still goes on with no host key. Landscape is 4: the title chip keeps its band, the face fills the phone, and a tap lays glyphs on a frosted 48px pill, with Hang up the only solid control (Q28, Q29, Q32). It is not a 5. Meet’s marks are smaller and its strip is thinner, so more of the face stays clear. Large type is 4: at a 32px root a tall phone grows to 88px controls and a 96px Hang up (Q30), and a short landscape grows to 56px controls in a 64px pill (Q33). Chat, the composer, and the lobby sentence already grow (Q21, Q24). FaceTime still wins that dimension. The rotated dock stops at 56px so the face stays a stage.
